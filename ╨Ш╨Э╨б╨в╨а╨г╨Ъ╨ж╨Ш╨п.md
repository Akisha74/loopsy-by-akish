# Как опубликовать сайт Loopsy by Akish

Это пошаговая инструкция для человека, который никогда этого не делал. Если что-то не получается — просто напишите мне, разберёмся вместе.

Всего сайт живёт на двух бесплатных сервисах:
- **GitHub** — здесь хранятся файлы сайта (как облачная папка с историей изменений)
- **Netlify** — здесь сайт "публикуется" и становится доступен по ссылке в интернете

Админка (страница, где вы будете менять фото/тексты/цены) работает поверх этих двух сервисов и ничего отдельно платить за неё не нужно.

---

## Шаг 1. Создайте аккаунт на GitHub

1. Зайдите на [github.com](https://github.com) и нажмите **Sign up**.
2. Укажите email, придумайте пароль и имя пользователя (логин). Логин лучше сделать простым, латиницей — он будет виден в технических настройках, но не на самом сайте.
3. Подтвердите почту по ссылке из письма.

## Шаг 2. Создайте репозиторий (папку для сайта)

1. На главной странице GitHub нажмите зелёную кнопку **New** (или "New repository").
2. Назовите его `loopsy-by-akish`.
3. Оставьте репозиторий **Public** (публичным — это не проблема, ваши тексты и фото это не персональные данные, а сам сайт всё равно будет виден всем в интернете).
4. Нажмите **Create repository**.

## Шаг 3. Загрузите файлы сайта

1. На странице только что созданного репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
2. Разархивируйте присланный вам файл `loopsy-site.zip` на компьютере — получится папка со всеми файлами сайта.
3. Откройте эту папку и перетащите **все файлы и папки изнутри** (не саму папку `loopsy-site`, а её содержимое) в окно загрузки на GitHub.
4. Внизу страницы нажмите **Commit changes**.

## Шаг 4. Укажите свой репозиторий в настройках админки

1. В репозитории откройте файл `admin/config.yml` (нажмите на него в списке файлов).
2. Нажмите на иконку карандаша (Edit this file).
3. Найдите строку:
   ```
   repo: ВАШ-GITHUB-ЛОГИН/loopsy-by-akish
   ```
4. Замените `ВАШ-GITHUB-ЛОГИН` на ваш логин из Шага 1. Например, если ваш логин `dmitrii-akish`, строка станет:
   ```
   repo: dmitrii-akish/loopsy-by-akish
   ```
5. Внизу страницы нажмите **Commit changes**.

## Шаг 5. Создайте аккаунт на Netlify и опубликуйте сайт

1. Зайдите на [app.netlify.com](https://app.netlify.com) и нажмите **Sign up**.
2. Выберите **Sign up with GitHub** — это проще всего, не нужно придумывать ещё один пароль.
3. После входа нажмите **Add new site → Import an existing project**.
4. Выберите **GitHub**, разрешите доступ, затем выберите репозиторий `loopsy-by-akish`.
5. Netlify сам предложит настройки сборки — ничего менять не нужно, просто нажмите **Deploy site**.
6. Через 30–60 секунд сайт будет опубликован. Netlify покажет ссылку вида `random-name-123.netlify.app` — откройте её, чтобы увидеть сайт.

### Как сделать ссылку красивее
В Netlify: **Site configuration → Change site name** — можно задать, например, `loopsy-by-akish.netlify.app`.

## Шаг 6. Войдите в админку

1. Откройте `https://ваш-сайт.netlify.app/admin/`
2. Нажмите **Log in with GitHub** и разрешите доступ.
3. Вы увидите панель с тремя разделами: **Товары**, **Отзывы**, **Тексты и контакты**.
4. Меняйте что нужно и нажимайте **Publish** — через минуту-две изменения появятся на сайте.

### Что сделать в первую очередь
- В разделе **Тексты и контакты** замените телефон, WhatsApp, Telegram, Instagram, email и город на настоящие — сейчас там примерные значения.
- Постепенно замените фото-примеры в товарах на настоящие фотографии через поле **Фотографии** у каждого товара.

## Как теперь пользоваться сайтом каждый день

Заходите на `ваш-сайт.netlify.app/admin/`, входите через GitHub (запомнится в браузере) и:
- добавляете/меняете товары, цены, описания, фото — в разделе **Товары**
- добавляете отзывы клиентов — в разделе **Отзывы**
- меняете любые тексты сайта (главная страница, "О нас", контакты) — в разделе **Тексты и контакты**

Кнопки "Заказать" на карточках товаров ведут в WhatsApp с уже готовым сообщением — покупателю останется просто нажать "отправить".

## Что нельзя поменять через админку (нужно будет попросить меня)

Сейчас на сайте пять категорий товаров (домики, миски + три "скоро"). Если в будущем понадобится **добавить совсем новую категорию** (не новый товар в существующей, а именно новый раздел каталога) — это небольшая правка кода, напишите мне, сделаю за пару минут.

## Про свой домен (например loopsybyakish.ru)

Это не обязательно — сайт прекрасно работает и на бесплатном адресе `....netlify.app`. Когда будете готовы:
1. Купите домен, например на [reg.ru](https://reg.ru) (~150–200 ₽/мес или дешевле при оплате на год).
2. В Netlify: **Site configuration → Domain management → Add a domain**.
3. Netlify покажет, какие записи нужно прописать у регистратора домена — просто скопируйте их в панель управления доменом.
4. Домен заработает в течение пары часов.
